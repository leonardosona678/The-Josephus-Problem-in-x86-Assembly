# The Josephus Problem in x86 Assembly

## About The Project

This repository contains a solution to the classic [Josephus problem](https://en.wikipedia.org/wiki/Josephus_problem), implemented entirely in low-level x86 Assembly. 

The project serves as a practical exploration of low-level programming concepts, including CPU register management, memory addressing, and the implementation of circular counting-out logic without the aid of high-level data structures.

## Features

* **Algorithmic Logic:** Implements the counting-out game to determine the final surviving position.
* **Low-Level Implementation:** Written strictly in x86 Assembly language.
* **Memory & Pointer Management:** Demonstrates manual handling of data and pointers for circular operations.

## Built With

* x86 Assembly
